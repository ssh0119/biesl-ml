- Mental1 11개, Mental2 10개, Physical1 11개, Physical2 12개입니다.
- 표의 `mta_9_14_pla_5'`는 사용자 확인에 따라 실제 `mta_9_14_pla_5'5`에 대응하며, 자극 길이는 305초로 처리했습니다.
- 파일 내용이 완전히 같은 중복 녹화는 없었습니다.
- 기존 평가 데이터에 비해 15개 추가, 1개 제외, `mta_6_3_math_14`가 Mental2에서 Mental1로 변경됐습니다.
- 정답 라벨은 새 표와 대응하는 `data_new` 폴더 기준입니다. 원본 파일/Excel은 수정하지 않았습니다.

## 평가 완료

43개 학습 / 1개 테스트의 44-fold를 모두 완료했습니다. 각 fold의 테스트 녹화는 내부 검증과 최종 학습에서 제외됐습니다. 내부 검증에서 정한 epoch와 확률 결합 가중치를 사용한 후, CNN과 XGBoost를 나머지 43개 전체로 재학습했습니다. 이전 데이터의 학습 모델이나 선택 결과는 재사용하지 않았습니다.

| 방식 | 정확도 | Macro F1 |
|---|---:|---:|
| CNN | 80.58% | 0.6978 |
| Plan C XGBoost | 76.82% | 0.6190 |
| 확률 단순 평균 | 83.46% | 0.7187 |
| 검증 선택 가중 결합 | 81.82% | 0.7062 |
| CNN 은닉층 96개 → XGBoost | 84.35% | 0.7502 |
| 생체 특징 12개 + 은닉층 96개 → XGBoost | 85.49% | 0.7567 |
| 생체 특징 12개 + pooling 256개 → XGBoost | **85.63%** | **0.7715** |

가장 높은 방식은 CNN 단독 대비 정확도 **+5.05%p**, Macro F1 **+0.0738**입니다. 단순 평균 대비로는 **+2.16%p**, **+0.0529**입니다. 비교 후보 중 가장 높은 관측값이며, 새로운 독립 데이터에서 우수성을 확인한 결과는 아닙니다.

## 남아 있는 혼동

가장 높은 성능의 모델에서 physical1 재현율은 54.63%입니다. physical1 723개 중 218개(30.15%)가 mental1으로 예측되어 주요 오분류로 남았습니다. 단순 평균 대비 mental2 재현율은 61.75%에서 82.42%로, physical2는 74.81%에서 80.56%로 높아졌지만 rest 재현율은 96.58%에서 93.82%로 낮아졌습니다.

## 확인한 항목

- 44개 fold 모두 학습 녹화 목록이 정확히 43개이며 테스트 녹화를 포함하지 않습니다.
- 내부 검증 4개 녹화는 최종 43개 학습 목록에 포함됩니다.
- 9,107개 녹화/시간 키가 중복 없이 한 번씩 테스트됐습니다.
- 일곱 방식의 전체 확률은 유한한 값이며, 행별 합이 1입니다.
- 예측 CSV에서 정확도, Macro F1, confusion matrix를 다시 계산해 결과 JSON과 일치함을 확인했습니다.
- CNN 체크포인트 44개와 최종 XGBoost 모델 176개를 확인했습니다.
- 최상위 모델의 confusion matrix 그림을 직접 확인했습니다.

## 구현 및 파일

- `scripts/evaluation/audit_phase_folders.py`: Excel/폴더 분류 점검, 파일명 별칭과 파일 해시 기록, 기존 결과의 라벨과 비교
- `scripts/evaluation/run_dataset_suite.py`: 데이터 수에 맞춘 내부 검증 및 전체 재학습, 일곱 방식 평가, 단계별 재시작, 결과 생성
- 기존 CNN 구조, Plan C 특징과 하이퍼파라미터, 신호 전처리를 재사용했습니다.
- `README.md`: 전체 결과·클래스별 재현율·confusion matrices·실행 방법
- `DATA_AUDIT.md`, `data_audit.json`: 라벨 대조 결과
- `folds/`: 모델·학습 목록·검증 기록·확률
- `predictions.csv`, `results.json`: 전체 예측과 지표
- `training-transcript.txt`, `runtime-packages.txt`, `run_config.json`: 실행 로그·환경·입력 및 코드 해시

녹화 단위 평가이므로 같은 참가자의 다른 녹화가 학습에 포함될 수 있습니다. 전체 녹화 정규화와 초기 rest 보정을 사용하는 오프라인 평가입니다. 이전 30개 데이터와 구성·라벨이 달라, 두 실험의 점수 차이를 모델 성능 변화만으로 해석하면 안 됩니다.
